# CodeAlpha_PhishingAwareness

Interactive phishing awareness training module for the CodeAlpha Cyber Security internship, Task 2.

## What's inside
A single self-contained web page (`index.html`, no dependencies) with:

1. **What is phishing**: phishing, spear phishing, whaling/BEC, smishing, vishing, fake sites
2. **Spot the phishing email**: a clickable fictional email with seven red flags to find
3. **Recognize fake websites**: how to read URLs, look-alike domains, decoy subdomains, the `@` trick
4. **Social engineering tactics**: urgency, authority, fear, greed, curiosity, trust
5. **Real-world examples**: Target (2013), US campaign emails (2016), fake Google Docs invite (2017), Twitter (2020)
6. **Best practices** plus a "what to do if you clicked" checklist
7. **10-question quiz** with instant feedback and a score

## Run it
Just open `index.html` in any browser. No install or server needed.

## Host it free (optional)
In the repo go to Settings > Pages > Deploy from branch > `main` / root. The page will be live at
`https://<your-username>.github.io/CodeAlpha_PhishingAwareness/`.

## Notes
- All brands used in examples (ExampleBank) are fictional.
- Works offline, supports light and dark mode, and is mobile friendly.
- Real-world cases are summarized from public reporting for educational purposes.
